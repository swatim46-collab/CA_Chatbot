# CA Assist

CA Assist is a static, responsive chatbot for general Chartered Accountant topics in India, including income tax, GST, TDS, ITR filing, and accounting. It is designed for individuals and small businesses who need quick, general information.

> **Disclaimer:** For general information only. Consult a qualified CA for advice.

## Features

- Conversational chat with full conversation context
- CA-focused answers generated by **Gemma 4 26B A4B IT** (`gemma-4-26b-a4b-it`) through the Google Gemini API
- Polite redirection for questions outside the supported CA topics
- Markdown-formatted assistant responses
- Thinking state, clear request errors, and a retry action
- New chat control; conversations are not persisted
- Responsive, keyboard-accessible interface with live announcements
- Static deployment to GitHub Pages through GitHub Actions

## Technology

- Vite, React, and TypeScript (strict mode)
- Plain CSS and `react-markdown`
- Google Gemini `generateContent` REST API via `fetch`
- GitHub Pages and GitHub Actions

The model is fixed in the application; there is no model selector, backend, database, or serverless function.

## Local development

**Prerequisites:** Node.js 20 and npm.

1. Install dependencies:

   ```sh
   npm ci
   ```

2. Create `.env.local` in the project root and set the Google AI Studio key:

   ```dotenv
   VITE_GEMINI_API_KEY=your_google_ai_studio_key
   ```

   Keep `.env.local` out of version control. The repository should ignore it.

3. Start the development server:

   ```sh
   npm run dev
   ```

The app reads the key from `import.meta.env.VITE_GEMINI_API_KEY`. Never put a real key in source files, documentation, commits, or logs.

## Checks and production build

```sh
npm run lint
npm run type-check
npm run build
```

The deployment workflow runs linting and type-checking before it builds the production site.

## GitHub Pages deployment

The GitHub Actions workflow is `.github/workflows/deploy.yml`. It is intended to deploy on pushes to `main` and manual `workflow_dispatch` runs.

1. In the repository settings, add an Actions repository secret named `GEMINI_API_KEY` containing the Google AI Studio key.
2. Ensure the workflow maps that secret to `VITE_GEMINI_API_KEY` for the build step.
3. Set the Vite production base path to `/CA_Chatbot/` for this repository.
4. In **Settings → Pages**, select **GitHub Actions** as the deployment source.

The site URL is `https://swatim46-collab.github.io/CA_Chatbot/` after a successful deployment.

### API key security note

Vite embeds `VITE_*` environment variables into the client-side bundle. Supplying the key through a GitHub Actions secret prevents committing it to the repository, but **does not keep it secret in the deployed website**: visitors can inspect browser assets and network requests. Restrict the Google API key to the intended API and, where supported, the site’s HTTP referrers; apply quotas and monitor usage. Do not use a broadly privileged key.

## Scope

CA Assist provides general information only and is not a substitute for advice from a qualified professional. It does not support accounts, saved chat history, document uploads, streaming responses, or non-CA topics beyond a polite redirect.
